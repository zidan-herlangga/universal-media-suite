Dokumentasi

Panduan lengkap penggunaan Universal Media & Document Suite di semua platform.

Unduh Aplikasi

Panduan Cepat

1 · Unduh binary

Pilih platform Anda lalu unduh berkas rilis terbaru sesuai sistem operasi.

Windows .exe Linux .AppImage macOS .dmg

2 · Siapkan FFmpeg

Windows sudah ter-bundle. Linux dan macOS perlu FFmpeg dari sistem agar modul video/audio berfungsi.

Ubuntu/Debian sudo apt install -y ffmpeg
macOS brew install ffmpeg

3 · Izinkan eksekusi

Linux: chmod +x. macOS: hapus atribut karantina bila perlu. Windows: pilih "Run anyway" jika SmartScreen muncul.

chmod +x ./UniversalMediaSuite.AppImage

4 · Jalankan aplikasi

Buka aplikasi, tarik file ke area drag-and-drop, pilih format tujuan, lalu klik tombol mulai.

Persyaratan Sistem

Kebutuhan minimum agar seluruh modul berfungsi penuh.

  • ✓Windows 10/11 64-bit, Linux x86_64 (glibc 2.31+), atau macOS 12+.
  • ✓LibreOffice (Linux/macOS) atau Microsoft Office (Windows) untuk konversi dokumen Office.
  • ✓FFmpeg tersedia di PATH sistem (khusus Linux/macOS).
  • ✓RAM 2 GB (disarankan 4 GB) dan ruang disk yang cukup untuk file hasil.

Dokumentasi Modul

01 · Foto & Kamera RAW

Mengekstrak data piksel mentah (bayer pattern) dari sensor kamera digital tanpa kompresi JPEG lossy bawaan vendor.

Input — CR2, CR3, CRW, NEF, NRW, ARW, SRF, SR2, RAF, ORF, RW2, PEF, PTX, DNG, X3F, ERF, MEF, MOS, KDC, DCR (RAW) + JPG, PNG, WEBP, BMP, TIFF, GIF, ICO, TGA, PPM, PCX, HEIC, HEIF, PSD (standar).
Output — JPG, PNG, WEBP, PDF, TIFF, BMP, ICO (otomatis dibatasi ≤ 256px), TGA.

Format tanpa transparansi (JPG/BMP/PDF) otomatis mengonversi RGBA → RGB untuk mencegah error. Resize memakai interpolasi LANCZOS untuk ketajaman maksimal.

02 · Video Transcoder & Resizer

Transkoding video massal untuk mengecilkan dimensi dan bitrate sambil menjaga rasio aspek.

Codec — Video: H.264 (libx264) · PixFmt yuv420p · Preset ultrafast · CRF 24. Audio: AAC stereo 128 kbps.
scale=w:h:force_original_aspect_ratio=decrease,pad=ceil(iw/2)*2:ceil(ih/2)*2

Filter pad menjaga dimensi selalu genap agar kompatibel dengan codec H.264.

03 · Audio Stream Extractor

Mengekstrak audio langsung dari kontainer video (MP4, MKV, MOV, WebM) dengan memangkas stream video (-vn).

Format: MP3 (libmp3lame) · AAC · M4A · WAV (pcm_s16le) · FLAC · OGG

Bitrate: 320/192/128/64 kbps. Mode 64 kbps ideal untuk voice note (hemat hingga 70% ukuran).

04 · Dokumen & PDF Tools

Konversi silang dokumen Office, plus alat gabung dan pisah PDF yang berjalan sepenuhnya lokal.

  • Windows: mengontrol Microsoft Office headless lewat Win32 COM (Word, Excel, PowerPoint).
  • Linux/macOS: automasi LibreOffice headless (soffice --headless --convert-to).
  • PDF → DOCX memakai engine pdf2docx. Gabung/pisah halaman memakai pypdf dengan sintaks rentang 1-5 atau 2,4,7.

05 · Network Media Downloader

Mengunduh media publik dari YouTube, TikTok, Instagram, X, dan SoundCloud tanpa situs downloader pihak ketiga.

Video resolusi tinggi dan audio digabung (mux) via FFmpeg lokal. Mode musik mengekstrak langsung ke MP3 192 kbps.

Verifikasi Checksum

SHA-256

Bandingkan nilai SHA-256 berkas yang Anda unduh dengan yang diterbitkan pada rilis.

Windows Get-FileHash .\UniversalMediaSuite_Setup.exe -Algorithm SHA256
Linux sha256sum ./UniversalMediaSuite.AppImage
macOS shasum -a 256 ./UniversalMediaSuite.dmg

Pemecahan Masalah

Windows SmartScreen Block

Peringatan muncul karena binary dikompilasi independen (belum ditandatangani sertifikat EV berbayar). Klik "More info" lalu pilih "Run anyway".

Linux — Izin Eksekusi

Jika AppImage tidak merespons, buka terminal dan tambahkan izin eksekusi dengan perintah di bawah.

chmod +x ./UniversalMediaSuite.AppImage
macOS — Gatekeeper Quarantine

Jika timbul pesan "App is damaged and cannot be opened", hapus atribut karantina melalui Terminal.

xattr -cr /Applications/UniversalMediaSuite.app

Pertanyaan Umum

Apakah aplikasi membutuhkan koneksi internet? ＋

Hanya untuk modul Media Downloader. Konversi foto, video, audio, dan dokumen berjalan sepenuhnya offline.

Mengapa versi Linux/macOS perlu FFmpeg tambahan? ＋

Untuk menjaga ukuran binary tetap kecil, FFmpeg pada Linux/macOS diambil dari sistem. Windows sudah menyertakan FFmpeg.

Apakah data saya dikirim ke server? ＋

Tidak. Seluruh proses berjalan lokal di perangkat Anda, kecuali Anda aktif mengunduh dari internet melalui modul downloader.
