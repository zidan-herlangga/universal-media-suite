Prinsip Arsitektur Perangkat Lunak

Isolasi I/O Lokal

Seluruh algoritma konversi berjalan pada subsistem OS lokal. Berkas perusahaan, rekam medis, atau dokumen bertanda tangan digital tidak pernah dikirim ke infrastruktur awan mana pun.

Worker Threads Mandiri

Eksekusi tugas I/O berat dialihkan ke daemon thread terpisah (`threading.Thread`). Antarmuka pengguna (UI) CustomTkinter dijamin bebas dari kondisi hang/freeze.

Ketahanan Batch (Fault Tolerant)

Jika berkas ke-42 dari 500 file corrupt, antrean konversi tidak berhenti tiba-tiba. File yang gagal akan dicatat secara mendalam pada file teks log lokal untuk audit pengguna.

Dokumentasi Teknis Modul

01. Image & Camera RAW Pipeline

Engine: Pillow + rawpy (LibRaw)

Modul ini menangani ekstraksi data piksel mentah (*bayer pattern*) dari sensor kamera digital profesional tanpa melewati kompresi JPEG lossy bawaan vendor.

Format Input yang Didukung: RAW: CR2, CR3, CRW (Canon), NEF, NRW (Nikon), ARW, SRF, SR2 (Sony), RAF (Fuji), ORF (Olympus), RW2 (Panasonic), PEF, PTX (Pentax), DNG (Adobe/ProRAW), X3F (Sigma), ERF, MEF, MOS, KDC, DCR.
Standar: JPG, JPEG, PNG, WEBP, BMP, TIFF, TIF, GIF, ICO, TGA, PPM, PCX, HEIC, HEIF, HIF, PSD.
Format Target Output: JPG, PNG, WEBP, PDF, TIFF, BMP, ICO (Auto-clamped ≤ 256px), TGA.

Logika Internal Penting:

• Normalisasi Ruang Warna: Format target tanpa saluran alfa (JPG/BMP/PDF) secara otomatis memicu konversi `img.convert('RGB')` untuk mencegah galat runtime (*RGBA to JPEG crash*).

• Resize Proporsional: Memanfaatkan interpolasi `Image.Resampling.LANCZOS` agar ketajaman detail garis pada foto resolusi tinggi tetap terjaga saat resolusinya diperkecil.

02. Video Transcoder & Resizer

Engine: FFmpeg CLI Pipeline

Modul transkoding video massal untuk mereduksi dimensi dan bitrate tanpa merusak rasio aspek gambar (*no stretched visual*).

Filter Graph: scale=w:h:force_original_aspect_ratio=decrease,pad=ceil(iw/2)*2:ceil(ih/2)*2
Video Codec: libx264 (H.264), Pixel Format: yuv420p (Kompatibilitas Global)
Audio Codec: AAC Stereo 128 kbps | Preset: Ultrafast | CRF: 24

Logika Internal Penting:

• Proteksi Dimensi Genap (Pad): Codec H.264 mewajibkan dimensi lebar dan tinggi berupa bilangan genap. Filter `pad=ceil(iw/2)*2:ceil(ih/2)*2` menjamin video ganjil tidak akan memicu galat kompilasi dari FFmpeg.

• Preset Resolusi Siap Pakai: 1080p FHD (1920x1080), 720p HD (1280x720), 480p SD (854x480), 360p (640x360), dan Manual Custom.

03. Audio Stream Extractor & Compressor

Engine: FFmpeg Demuxer

Ekstraksi audio langsung dari berbagai kontainer video (MP4, MKV, MOV, WebM) dengan memotong stream video secara utuh (`-vn`) guna menghemat siklus CPU.

Format Output Codec Handler Tujuan Penggunaan
MP3 libmp3lame Distribusi umum & pemutar musik portabel
AAC / M4A aac Ekosistem Apple & efisiensi kompresi tinggi
WAV pcm_s16le Format mentah uncompressed untuk editing audio
FLAC flac Arsip audio kualitas lossless bit-perfect

Pilihan bitrate variabel/konstan: 320 kbps (Master/Studio), 192 kbps (Standar Musik), 128 kbps (Efisien), dan 64 kbps (Kompresi rekaman suara / voice note untuk memangkas ukuran hingga 70%).

04. Document & PDF Manipulation

Engine: Win32 COM / LibreOffice / pypdf

Menghilangkan ketergantungan pada situs web konverter dokumen daring. Menjamin berkas sensitif (kontrak, laporan keuangan, transkrip) tidak bocor ke pihak ketiga.

A. Konversi Silang Dokumen: • Windows: Mengontrol MS Office headless melalui Win32 COM Dispatch (`Word.Application`, `Excel.Application`, `PowerPoint.Application`).
• Linux/macOS: Menjalankan automasi headless LibreOffice (`soffice --headless --convert-to`).
• PDF to Word: Engine `pdf2docx` mengekstrak tata letak teks, font, dan tabel kembali ke format `.docx`.
B. Multi-Tool PDF (Merge & Split): • Merge PDF: Menggabungkan array berkas PDF tak terbatas menjadi satu file terstruktur secara lokal di RAM menggunakan `PdfWriter`.
• Split PDF: Mengekstrak halaman menggunakan ekspresi rentang fleksibel, seperti 1-5, 2,4,7, atau kombinasi keduanya.

05. Network Media Stream Downloader

Engine: yt-dlp + FFmpeg Post-processor

Mengunduh konten multimedia publik dari ribuan platform daring (YouTube, TikTok tanpa tanda air, Instagram Reels, X/Twitter, SoundCloud) secara langsung tanpa perantara situs downloader pihak ketiga yang penuh adware.

• Muxing Stream Resolusi Tinggi: YouTube menyimpan video 1080p/4K dan audio dalam stream terpisah. Engine secara otomatis mendownload keduanya lalu menggabungkannya ke MP4 melalui FFmpeg lokal.
• Post-Processor Audio: URL musik atau podcast otomatis diekstrak langsung ke format MP3 192 kbps menggunakan modul internal `FFmpegExtractAudio`.
• Real-Time UI Hooks: Menghitung persentase progres biner, kecepatan unduh aktual (MB/s), serta perkiraan waktu selesai (ETA) secara live.

Get-FileHash .\UniversalMediaSuite_Setup.exe -Algorithm SHA256

Panduan Penanganan Galat Eksekusi (Troubleshooting)

1. Windows SmartScreen Block:

Peringatan muncul karena binary dikompilasi secara independen (belum ditandatangani sertifikat EV berbayar). Klik "More info" lalu pilih "Run anyway".

2. Izin Eksekusi Linux (AppImage):

Jika file AppImage tidak merespons klik ganda, buka terminal di folder tersebut lalu jalankan: chmod +x ./UniversalMediaSuite.AppImage.

3. macOS Gatekeeper Quarantine:

Jika sistem macOS menampilkan pesan "App is damaged and cannot be opened", hapus atribut karantina via Terminal: xattr -cr /Applications/UniversalMediaSuite.app.
