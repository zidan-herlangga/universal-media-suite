Mengapa Memilih Suite Ini?

01

Isolasi I/O Lokal

Semua konversi berjalan di perangkat Anda. Dokumen, foto, dan media tidak pernah dikirim ke server awan mana pun.

02

Worker Threads Mandiri

Proses berat dijalankan pada tread terpisah sehingga antarmuka tetap responsif dan tidak pernah membeku.

03

Ketahanan Batch (Fault Tolerant)

File yang korup tidak menghentikan antrean. Setiap kegagalan dicatat ke file log lokal untuk audit mudah.

Modul Utama

Lima modul terintegrasi dalam satu aplikasi desktop.

Foto & Kamera RAW

Pillow + rawpy (LibRaw)

Baca file mentah kamera profesional (CR2, NEF, ARW, DNG, dll) lalu konversi massal ke JPG, PNG, WEBP, atau PDF dengan opsi resize.

Video Transcoder

FFmpeg CLI Pipeline

Perkecil resolusi ratusan video sekaligus dengan preset 1080p/720p/480p/360p atau dimensi custom, tanpa merusak rasio aspek.

Ekstraktor Audio

FFmpeg Demuxer

Ekstrak trek audio dari video ke MP3, AAC, M4A, WAV, FLAC, atau OGG dengan bitrate hingga 320 kbps.

Dokumen & PDF

Win32 COM / LibreOffice / pypdf

Konversi dokumen Office, gabung & pisah PDF, dan ekstrak teks — sepenuhnya lokal.

Media Downloader

yt-dlp + FFmpeg

Unduh video/audio dari YouTube, TikTok, Instagram, X, dan SoundCloud langsung ke folder Anda.

Windows PowerShell

Pemecahan Masalah

Windows SmartScreen Block

Peringatan muncul karena binary dikompilasi independen (belum ditandatangani sertifikat EV berbayar). Klik "More info" lalu pilih "Run anyway".

Linux — Izin Eksekusi

Jika AppImage tidak merespons, buka terminal dan tambahkan izin eksekusi dengan perintah di bawah.

chmod +x ./UniversalMediaSuite.AppImage
macOS — Gatekeeper Quarantine

Jika timbul pesan "App is damaged and cannot be opened", hapus atribut karantina melalui Terminal.

xattr -cr /Applications/UniversalMediaSuite.app

Pertanyaan Umum

Apakah aplikasi membutuhkan koneksi internet? ＋

Hanya untuk modul Media Downloader. Konversi foto, video, audio, dan dokumen berjalan sepenuhnya offline.

Mengapa versi Linux/macOS perlu FFmpeg tambahan? ＋

Untuk menjaga ukuran binary tetap kecil, FFmpeg pada Linux/macOS diambil dari sistem. Windows sudah menyertakan FFmpeg.

Apakah data saya dikirim ke server? ＋

Tidak. Seluruh proses berjalan lokal di perangkat Anda, kecuali Anda aktif mengunduh dari internet melalui modul downloader.
